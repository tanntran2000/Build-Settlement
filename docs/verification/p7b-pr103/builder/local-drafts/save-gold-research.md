## Size

The empty v12 proposal is 17360 bytes and three B1 complete NPC/profile pairs add 4790 bytes at the same opening Gold. Allow roughly 1.6 KB per pair plus 0.4 KB for household and generator counters and 0.7–1 KB for a 20-entry recent-history envelope. For 100 owned NPCs this projects to about 290–320 kB. A conservative 4 KB per pair plus the base state is below 420 kB. Verify actual UTF-8 bytes and byte-identical reserialize with valid home levels. B1's JS and CSS gzip total is 153.265 kB, leaving 46.735 kB against the 200 kB guidance. The final bundle requires a measured build.
