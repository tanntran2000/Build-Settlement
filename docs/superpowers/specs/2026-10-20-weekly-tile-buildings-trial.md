## Workforce assignment clarification — 2026-10-21

Workforce is reusable shared capacity, not inventory consumed or charged again each week. Reassigning a building replaces its previous amount; the shared total changes only by new amount minus old amount. Other buildings' assignments do not change. Existing state/dispatcher behavior already satisfies this contract; this clarification does not authorize a replacement workforce mechanism.
